# ML Algorithms for learning project

This my implementation of popular machine learning algorithms for educational purposes

## To start developing this lib with me:

### 1. Clone the repo

```
git clone https://github.com/Alexguzanov/ml_algos.git
```

### 2. Install uv dependeces manager 

``` 
pip install uv
```

### 3. Install requirements 

```
uv sync
```

### 4. Before commit check and fix formating with ruff 
pre-commit will automaticly validate formating and block your commit if formating is wrong

```
uv run ruff check --fix .
uv run ruff format .
```
